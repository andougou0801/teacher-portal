# 管理画面ですべて編集できるようにする手順（SQLの実行）

2026-10-31 に、10カテゴリーすべてを管理画面から編集できるようにしました。
**コードを本番に反映しただけでは、まだ編集できません。**
Supabaseで下のSQLを5回実行して、はじめて使えるようになります。

> **2026-11-01 に5本とも実行済みです。** 以下は、やり直すときのための記録です。
> 登録件数：公式サイト集45件／AI活用5件／まとまり2件・用語7件／カテゴリー10件／
> アイスブレイク66件・学級レク60件。

## 大事なこと

- **サイトの表示は、SQLを実行する前でも今までどおりです。**
  データベースに中身が無いときは、これまでのコードの内容を表示します。
  途中で止めても、サイトが白くなったり記事が消えたりすることはありません。
- **1つずつ、好きなときに実行して大丈夫です。** 全部まとめてやる必要はありません。
- **何度実行しても安全です。** すでに登録済みのときは、何も起きません。

## 実行する場所

Supabase の SQL Editor（新しいクエリ）

https://supabase.com/dashboard/project/eyakvgrrbbjbnyuzqrcj/sql/new

ファイルの中身をぜんぶコピーして貼り付け、「Run」を押すだけです。

> Chromeの自動翻訳が入っていると、Supabaseの画面のボタン名が変に訳されて
> 分かりにくくなります。翻訳はオフにしてください。

## 実行したあとの確かめ方

1. 管理画面（https://teacher-portal-puce.vercel.app/admin ）を開く
2. その番号のメニューを開く（例：1番なら「便利な公式サイト集」）
3. **一覧に中身が出ていれば成功**です
4. 「SQL Editorで1回実行してください」と出たときは、まだ実行できていません

サイト側（/links など）の表示は、最大1分で切りかわります。

## うまくいかないとき

- **「is_admin() does not exist」と出た**
  → 先に `supabase/admin_setup.sql` を実行してください（最初の設定です）
- **管理画面で「権限がありません」と出る**
  → `admin_setup.sql` の `is_admin()` に書いてあるメールアドレスでログインしているか確かめてください
- **一覧が空のまま**
  → すでにそのテーブルに1件でも中身があると、登録はスキップされます。
    いったん空にしてから実行し直すか、管理画面から手で足してください
