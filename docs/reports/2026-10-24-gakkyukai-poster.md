## 作ったもの

デスクトップの `学級会の掲示セット.html`（サイト側は `/tools/gakkyukai-poster.html`）。
運営者の「学級会での掲示『議題』『めあて』などの学活系を強くしたい」という希望から作った。
B-020（話し合いの仕方カード）と対になる1本。

議題・提案理由・めあて・話し合うことを入力すると、**黒板に貼れる大きさの札**が
1枚に1つずつ印刷できる。出せるのは次の7種類で、いらないものはチェックを外せる。

| 札 | 中身 |
| --- | --- |
| 議題 | 大きな文字で1枚 |
| 提案理由 | 文が長いので少し小さめの文字に自動調整 |
| めあて | 大きな文字で1枚 |
| 話し合うこと | ①②を番号つきの帯で |
| 話し合いの流れ | 提案理由を聞く→出し合う→くらべ合う→まとめる→決まったことをたしかめる（説明つき） |
| 役割 | 司会・副司会・記録・黒板記録（それぞれの仕事つき） |
| 決まったこと | 書きこみ用の罫線 |

用紙は黒板に合う**よこ向きが既定**（たてにも変更可）。文字の大きさは3段階で、
「特大」にすると後ろの席からも読める。低学年向けにひらがなを多めにする切りかえつき。

## 確認したこと

- `npm run lint`・`npm run build`：成功（221ページ）
- ブラウザのエラー表示：なし
- 7種類の札がすべて作られることを確認
- **1枚に収まることを実測**（よこ向きA4で使える高さ186mm）
  - はじめ「話し合いの流れ」だけ199mmで**はみ出していた**ので、帯の余白と文字を詰めて収めた
  - 直したあとは、**文字を「特大」にしても7枚すべてが1枚に収まる**
- 長い議題（46文字）を入れても、用紙からはみ出さず、意味のまとまりで折り返すことを確認
- スマホ幅（375px）で横にはみ出さないことを確認
- ハードリンク（デスクトップ側との結びつき）を確認

## 測り方について（前回の教訓を活かした／一部活かせなかった）

前回（B-020）、縮小表示された見かけの高さを測って判断を誤った。今回も最初に
同じ間違いをしかけたが、数値が不自然に小さい（全部61mm）ことに気づいて測り直した。

**`getBoundingClientRect()` は縮小表示（transform）の影響を受けるが、
`offsetHeight` は受けない。** 用紙が1枚に収まるかを測るときは `offsetHeight` を使うこと。
この点を `CLAUDE.md` に書き足したほうがよい（まだ書いていない）。
