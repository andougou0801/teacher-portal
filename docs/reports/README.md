# 作業報告の置き場

定期作業（昼12:00・深夜1:00）の報告を、ここに1回につき1ファイルで保存します。

- ファイル名：`YYYY-MM-DD-noon.md`（昼）／ `YYYY-MM-DD-night.md`（深夜）
- 深夜1:00の回は、**その日の日付**で保存します（例：10月19日の午前1時 → `2026-10-19-night.md`）

## 書く内容

1. やったこと（箇条書き）
2. 作業用ブランチ名とプレビューURL（実装した場合）
3. チェック担当の確認結果（動作・スマホ表示・リンク切れ・誤字・個人情報ルール違反）
4. バックログに追加した提案（最大3件）
5. うまくいかなかったこと・エラー（**隠さず正直に書く**）

## 注意

報告にも個人情報ルールが適用されます。
運営者の本名・勤務校・地域・担当学年などは書きません。
