### B-003 `/life` の自治体の偏りをなくした（済・確認待ち）

「〇〇県のケースを例に」と書いていた。全国向けのサイトで1県だけを例にしていると、

置きかえた先（すべて全国共通・リンクが開けることを確認済み）：

| 置きかえ前 | 置きかえ後 |
| --- | --- |
| 県の教育委員会「教職員の働き方改革」 | 文部科学省「学校における働き方改革について」 |
| 公立学校共済組合の県支部 | 公立学校共済組合（本部） |

本文は「お住まいの都道府県・市区町村名＋〇〇で検索してください」という案内に変えたので、
どの県の先生が読んでも同じように使える。

## 4. チェック担当の確認結果と、それを受けた修正

実装したのとは別の担当に確認してもらったところ、**送信前チェックの誤検知が多すぎる**
という重大な指摘があった。「通う小学校」「ある小学校では」「来年度、小学校から中学校へ異動」
のような、ごく普通の文章まで警告していた。保護者対応や異動の相談ではよく出る書き方なので、
このままだと先生が警告に慣れて読み飛ばしてしまう。

そこで判定の考え方を「**見逃してもよいから、明らかなものだけを拾う**」に変えた。
学校名は、漢字・カタカナだけで書かれた短い名前が「小学校」などの直前にあるときだけ拾う。

直した誤検知（警告が出なくなった）：

- 「来年度、小学校から中学校へ異動することになりました」
- 「新しい小学校」「大きい小学校」「ある小学校では」「元小学校」「毎年小学校」
- 「担任をしている小学校」「通う小学校」「卒業した小学校」
- 「県立高校」「市立小学校」「区立小学校」「夜間中学校」
- 「子どもが通う保育園」
- いじめ相談の電話「0120-0-78310」（フリーダイヤルは警告しない）
- 日付の「05-10-2025」

あわせて直した見逃し（警告が出るようになった）：

- 「桜ヶ丘小学校」「佐々木小学校」（「ヶ」「々」が判定から外れていた）
- 「山本小学校」「橋本小学校」（「本」で終わる校名が例外に当たってしまっていた）
- 「緑小学校」（1文字の校名）
- 「3年A組」「3年生2組」「第3学年2組」
- 全角で書いた電話番号、全角＠のメールアドレス
- **ニックネーム欄**（これまで本文しか見ていなかった）

その他に直したこと：

- 「消したいときは通報ボタンから」という案内が、実際の動き（本人は消せない／
  通報ボタンは質問の詳細ページにある）と合っていなかったので書きかえた
- 警告に `role="alert"` を付け、画面読み上げソフトにも伝わるようにした

**判定を変えたときに確かめられるテストを作った。**
`scripts/check-personal-info-detection.mjs` に、警告が出てはいけない文章18件と
出るべき文章14件を入れてある。実行方法：

```
node --experimental-strip-types scripts/check-personal-info-detection.mjs
```

現在は32件すべて期待どおり。判定をいじったら必ず実行することを `CLAUDE.md` に書いた。
