## 何が起きていたか

ハードリンクの点検で、デスクトップの元ファイルとサイト側の中身が食い違っていた。

| | 日付 | 大きさ |
| --- | --- | --- |
| サイト側（公開中） | 2026-09-19 | 67,549バイト |
| デスクトップ側 | 2026-09-23 | 72,455バイト |

9月23日の改良が、サイトに出ないまま4日ぶん取り残されていた。
ハードリンクが切れていたため、デスクトップ側を直してもサイトに反映されない状態だった。

## 改良の中身

**わり算の筆算の「計算過程」が出るようになる。**

公開中のものは、わり算の筆算の枠は出るが、かけて引いていく途中の段が出なかった。
新しいほうは、途中の式が位をそろえて1段ずつ出る。Word用の書き出しでも同じように出る。

長い割り算で子どもがつまずくのはこの途中の処理なので、意味のある改良と判断した。

## 正しさの確認

勝手に公開せず、検証用のコピーを一時的に置いて動かし、確認後に消した。

- **わり算の計算過程を11,760通り検算して、誤りゼロ。**
  2〜99で割る組み合わせを無作為に試し、次をすべて確認した。
  - 「商 × わる数 ＋ あまり ＝ わられる数」が成立する
  - 各段のあまりがわる数より小さい
  - 各段の引く数がわる数の倍数で、引かれる数以下である
  - あまりが `わられる数 % わる数` と一致する
- たし算・ひき算・かけ算の筆算も、これまでどおり正しく出る（31＋35＝66 などで確認）
- ブラウザのエラー表示なし
- 公開中の機能が減っていないことを、入れ替わった関数を追って確認した
- 反映後に本番と同じ経路で読み込み、946 ÷ 11 = 86 の計算過程が正しいことを再確認
- `npm run lint`・`npm run build` ともに成功（217ページ）

## 残っている疑問（正直に）

**この改良を9月に誰が何のために作ったのか、記録が残っていない。**
作りかけで止めたものである可能性は完全には否定できないが、動かした限りでは
作りかけには見えなかった。運営者が画面を見たうえで公開を判断した。

## 再発を防ぐために

ハードリンクが切れたまま放置されると、今回のように「直したのに反映されない」が起きる。

書き足してある（デスクトップ側を編集したら デスクトップ側 → サイト側）。
定期的に全ツールのリンク数を点検するとよい。
