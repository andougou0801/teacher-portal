# 2026-10-18 スマホ表示の崩れを直した（B-001・B-002）

- ブランチ：`fix/mobile-header-and-cards`
- 本番（`master`）への反映は**していない**

## やったこと

### B-001 ヘッダーの「サイトについて」ボタン（済・確認待ち）

スマホの幅（375px）で、題名とボタンが並びきらず、ボタンの文字が
「サ／イ／ト／に／つ／い／て」と1文字ずつ縦に崩れていた。全ページの一番上に出るので目立つ。

直し方：

- 幅の狭い画面では、この丸いボタンを隠した
- 代わりに「☰」のメニューの一番下に「サイトについて」を足した（迷子にならないように）
- 題名の文字をスマホでは少し小さくし、折り返さないようにした
- ヘッダー左右の余白を、スマホでは少しつめた

パソコンの画面では、これまでと見た目は変わらない。

### B-002 カテゴリーカードの見出し（済・確認待ち）

トップページのカード見出しが「先生の便利ツー／ル」のように単語の途中で折り返していた。

直し方：日本語を意味のまとまりで折り返す指定（`word-break: auto-phrase`）を入れ、
スマホではカードの内側の余白を少しつめた。「授業・／教材アイデア」のように切れるようになった。
この指定に対応していないブラウザ（Safariなど）では、これまでどおりの折り返しになるだけで、
表示が壊れることはない。

### ついでに直したもの：トップページの「検索する」ボタン

作業中に気づいた。同じ原因で「検／索／す／る」と縦に崩れていたので直した。
バックログには載っていなかったが、同じ画面の同じ種類の崩れなので一緒に直している。

## 確認したこと

- `npm run lint`：エラーなし
- `npm run build`：成功
- 375px幅で、トップ・`/tools`・`/life`・`/community`・`/kids` のどれも
  **横にはみ出していない**（はみ出し 0px を画面上で計測）
- カードが2列で並び、見出しが単語の途中で切れていないことを確認
- 「☰」メニューに「サイトについて」が入っていることを確認

## 注意

「検索する」ボタンを横1行にしたとき、一度は入力欄と並びきらず**横にはみ出した**。
入力欄が縮めるようにする指定（`min-w-0`）を足して直した。
ボタンを `shrink-0` にするときは、となりの入力欄に `min-w-0` が要る。
