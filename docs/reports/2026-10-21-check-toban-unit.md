# 2026-10-21 当番表メーカー・たんいマスターの検証（B-008・B-009）

定期作業が作った2つのツールを、作った担当とは別の目で確認した記録。

## 1. 計算が合っているかを確かめた

### たんいマスター（B-009）：**5000問を自動で検算して、誤りゼロ**

出題のしくみを直接呼び出し、**5000問を作って答えを1問ずつ検算**した。
ツールが出す答えと、こちらで独立に計算した答えが、5000問すべて一致した
（小数の答えが出るモードも含む）。

単位の関係そのものも一つずつ確かめた。すべて正しい。

| | 確かめた関係 |
| --- | --- |
| 長さ | 1km=1000m、1m=100cm、1cm=10mm |
| かさ | 1kL=1000L、1L=10dL、1dL=100mL、1L=1000mL |
| 重さ | 1t=1000kg、1kg=1000g、1g=1000mg |
| 面積 | 1km²=100ha、1ha=100a、1a=100m²、1ha=10000m²、1m²=10000cm² |
| 時間 | 1日=24時間、1時間=60分、1分=60秒、1日=86400秒 |

**学年のわけ方も確認した。** アール・ヘクタールが4年生に入っているのを
誤りかと思って調べたが、学習指導要領では第4学年の「内容の取扱い」で
アール・ヘクタールに触れることになっており、**ツールのほうが正しかった**ので直していない。

### 当番表メーカー（B-008）：**90通りの設定で、公平さは一度も崩れなかった**

人数（1・2・5・30・40人）× 交代の区切り（毎日・毎週・3日ごと）× 期間（1・4・12週）×
土日を除く/除かない の **90通り**を自動で試した。

- **当番ごとの回数の差は、どの設定でも1回以内**（崩れた回数：0）
- 枠の数が合わないことも、一度もなかった
- 祝日が正しく除かれることも確認（例：2026年11月3日の文化の日が飛ばされる）

## 2. 見つかった問題と、直したこと

### 直した：見出しの番号が飛んでいた（当番表メーカー）

画面の見出しが ⑤ → ⑦ → ⑧ と、⑥ を飛ばしていた。⑥⑦ に詰めた。

### 直せていない：人数が当番の枠とほぼ同じときだけ、同じ人が2つの当番になる

当番の枠の合計（既定では日直1＋給食2＋そうじ2＝5人分）と、名簿の人数が
ほぼ同じときに、**ある週だけ同じ子が2つの当番にあたり、別の子が0になる**ことがある。

実測した割合（12週・20回ずつ試した結果）：

| 名簿の人数 | 同じ人が重なった週の割合 |
| --- | --- |
| 5人 | 8.8% |
| 6人 | 0.4% |
| 7人以上 | **0%** |
| 30人・40人 | **0%** |

**通常の学級（20〜40人）では一度も起きない。** 起きるのは、少人数の学級で
当番の枠を人数いっぱいまで増やした場合だけ。

直そうとして、重なりを解消する処理の回数を6回から40回に増やしてみたが、
**結果は変わらなかった**（23件→23件）。当番ごとに別々の順番で回す作り方の上では、
人数と枠がぴったり同じときに毎回きれいに分けるのは、局所的な入れかえでは届かない。
やるなら割りあての作り方自体を変える必要があるため、いったん元にもどし、
**B-019 として提案に登録した**。

回数の公平さ自体は保たれており、表としては使えるので、公開は止めていない。
