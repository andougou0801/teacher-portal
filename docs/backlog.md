# 提案・作業の一覧（バックログ）

このファイルは「これからやること」の置き場です。
運営者が承認したものだけを実装します。**状態が「承認済み」でない案は実装しません。**

## 状態の意味

| 状態 | 意味 |
| --- | --- |
| 提案中 | エージェントが出した案。運営者の返事待ち |
| 承認済み | 運営者がOKを出した。実装してよい |
| 作業中 | 実装している途中 |
| 確認待ち | 実装が終わり、プレビューで確認してもらう段階 |
| 一部完了 | できるところまでやったが、運営者の操作が残っている |
| 公開済み | 本番サイトに反映済み |
| 却下 | やらないことに決めた |

## 書き方

- IDは `B-001` から連番。一度使った番号は再利用しない
- 1行に1件。詳しいことは「メモ」欄に短く書く
- 運営者が「1と3はOK、2はやめる」と番号で返事をしたら、その場で状態欄を書き換える
