# 「かずのまち」 先生のつかいかた（A4・1枚で印刷する想定）

対象：小学1年生・算数（1学期）／1回15分
ひらく場所：`https://teacher-portal-puce.vercel.app/study-game/index.html`
（ホーム画面に追加しておくと、オフラインでも開けます）

## はじめる前に（先生が1回だけ）

1. 1台ずつ開いて、**タイトルの文字「かずのまち」を3秒長押し** → 4けたの暗証番号を決める
   （この番号は**紙に控えて**ください。忘れたときは、ブラウザの「サイトのデータを消去」で
   全部消すしかありません＝子どもの記録も消えます）
2. 同じ画面で「1日のめやす」を 10／15／20分から選ぶ（はじめは15分）
3. 音は**はじめからオフ**です。家庭学習で使う子には、最初の画面の
   「🔈 おと オフ」を押せば音が出ることを伝えてください

## 子どもがやること（はじめの1回だけ）

1. 「はじめて あそぶ」を押す
2. 自分の**出席番号**を押す（10人ずつに区切って並んでいます）
3. 自分の**かお**を選ぶ
4. 「これで いい？」の画面で、番号と顔をたしかめて「これで いい」

2回目からは、**最初の画面にある自分の番号のボタンを1回押すだけ**で続きから始まります。

## 1回の流れ（15分）

町 →「きょうの ぼうけん」→ 行き先を選ぶ → 1ステージ8問 → 材料をもらう →
（まん中で20秒の目やすみ）→ まとめ → 町にもどって建物を建てる → 「きょうは おしまい」

- 15分たつと**延長できません**。そのあとは記録だけ残る「れんしゅう」になります
- 終わる2分前に「あと 2ふんで きょうは おしまい」と出ます
- まちがえても負けません。「もうすこし！」と正しい答えが出て、同じ種類の問題がまた出ます

## 授業で使うとき（先生モード）

タイトルを3秒長押し → 暗証番号 → 次のことができます。

| できること | 使うとき |
| --- | --- |
| つまずいているところ | この端末の子のうち、3回以上やって正答6割未満のものを出席番号ごとに表示 |
| じゅぎょうタイマー | 5／10／15／20／45分に差しかえ（終わると元のめやすに戻る） |
| かいほうコード | 単元の名前を押すだけで、そこまで開く（転入・欠席の子を追いつかせる用） |
| きろくの書き出し・読みこみ | 学期末に1台ずつファイルに残す |
| セーブコード | 端末を変えるときに使う（コピーボタンあり） |
| 子どもの一覧・削除 | 学年の終わりに、ここで全員を消してから次の学年へ渡す |

※ サーバーを使っていないので、**クラス全員の進み具合を1画面で見ることはできません**。
　 見られるのは「その1台の中の子」だけです。評価には使わない前提でお使いください。

## 子どもにわたす操作カード（A4・絵を大きく・文はこれだけ）

1. じぶんの ばんごうの タブレットを もつ
2. がめんを ひらく
3. じぶんの ばんごうを おす
4. かおと ばんごうを みて「これで いい」を おす
5. もんだいを ゆびで えらぶ（おとは でません）
6. 「きょうは おしまい」が でたら、とじる。こまったら てを あげる

---

## 保護者へのおたより（5行）

1. 学校のタブレットで、算数の練習ができるサイトを使います。
2. 記録はそのタブレットの中だけに残り、名前は集めません（出席番号とキャラクターの絵だけです）。
3. ご家庭のスマートフォンなどでは、同じ記録は使えません。
4. 1回15分で終わります。延長はできません。くじ引き・課金・広告はありません。
5. 困ったことがあれば、連絡帳か担任までお知らせください。

---

## 使う前に先生が確かめておくこと（6人で10分試す前に）

1. 6人ぶんの番号で、「開始 → 確認 → 問題 → 閉じる → もう一度開いて続きから」が通るか
2. 6台同時に開いて、音が鳴らないか（はじめはオフになっています）
3. 1台を2人で使ったとき、先生モードの一覧で番号が混ざらないか
