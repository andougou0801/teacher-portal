# ゲーム設計書「かずのまち」

通年型の勉強ゲーム。第1回会議（`meetings/2026-11-21-01.md`）で決まったことをまとめたもの。
**作業を始めるときは、この design.md と decisions.md、progress.md を先に読む。**

## 1. 何を作るのか

数が消えてしまった町に「かず」を取りもどし、町を作り直していくゲーム。
算数の問題を解くと材料が手に入り、町に建物が建ち、アバターが育つ。

- **ゲーム名**：かずのまち（教科を変えて横に増やせる名前。姉妹作は「ことばのまち」）
- **最初に作る範囲**：小学1年生・算数・1学期（8単元）
- **置き場所**：`public/study-game/`（複数ファイル）、サイトからは `/tools/kazu-no-machi` で開く
- **端末**：iPad（キーボード付きカバー）。学校で使う。オフラインでも動く
- **1日の目安**：15分。延長はできない

### 出発点（忘れてはいけないこと）

このゲームは「**タブレット依存を防ぐ**」ために作る。規制ではなく、学べるゲームを用意する発想。
だから、**ゲーム自体が依存を生む作りにしない**。この原則が、面白さより優先する。

## 2. 絶対に入れないもの

| 入れないもの | 理由 |
| --- | --- |
| ガチャ・くじ引き・ランダム報酬 | 「出るまで回す」は依存を最も強く作る |
| 連続ログイン報酬・ストリーク表示 | 休むと損になり、休めなくなる |
| 順位表・正答率％・他の子との比較 | 終わりのない比較を生む |
| スタミナの時間回復 | 回復時刻に端末へ呼び戻す |
| 放置収益・建設の待ち時間 | 「見に行かないと損」で15分の外に引き戻す |
| 期間限定イベント・今日だけアイテム | 取り逃し不安で毎日に縛る |
| 寸止め演出（あと1問で◯◯） | 中断が不快になる |
| 無限モード・ミスで消えるコンボ | 自分で区切れなくなる |
| 課金・広告・外部リンク・外部CDN・アクセス解析 | 子ども向けページの方針 |
| 本名・学校名の入力、文字入力そのもの | 個人情報を持たない。小1は打てない |
| 通知・リマインド | 外から呼び戻す装置になる |

**町の見た目は、学習量だけで変わる。時間の経過では1ドットも変わらない。**

## 3. 1回15分の流れ

```
はじめ（出席番号＋キャラ絵をえらぶ／つづきから）
  ↓
まち（ハブ）── きょうのぼうけん ─→ ちず（3つのステージ）
  │                                   ↓
  ├ アバター                      たたかう（1ステージ6〜8問）
  ├ ずかん                            ↓
  ├ きろく                        ステージのけっか（材料をもらう）
  └ せってい                          ↓  ×3（真ん中で20秒の休憩）
                                  きょうのまとめ（できるようになったこと）
                                      ↓
                                  まち（建物を建てる・アバターを強くする）
```

| 時間 | すること |
| --- | --- |
| 0〜1分 | 町の画面。今日のしごとが1つだけ光る |
| 1〜6分 | ステージ1（6〜8問）→ 材料をもらう |
| 6分すぎ | 20秒の休憩画面（遠くを見る。1回だけ） |
| 6〜11分 | ステージ2、ステージ3 |
| 11〜13分 | きょうのまとめ（できるようになったこと3行＋今日いちばん難しかった問題） |
| 13〜15分 | 町にもどって建物を建てる・アバターを1か所強くする |
| 15分 | 「きょうは おしまい」。ボタンは「とじる」だけ |

**15分を使い切ったあと**は「れんしゅうモード」になる（問題は解けるが材料も建物も増えない）。
終わりの画面では、止めるのではなく**明日の予告**を見せる（「あしたは 〈はかりのとう〉が たてられます」）。

## 4. 学習の中身（小1算数・1学期）

出典：国立教育政策研究所 学習指導要領データベース
<https://erid.nier.go.jp/files/COFS/h29e/chap2-3.htm>（平成29年告示・第2章第3節 算数）

小1で使える記号は **＋ − ＝ 一の位 十の位** だけ。×÷＜＞・カッコ・小数・分数は使わない。

| ID | 単元 | 指導要領の対応 | 問題の形式 |
| --- | --- | --- | --- |
| u01 | 10までのかず | A(1)ア(イ)(ウ) | 選択（●を数える）／並べ替え（小さい順） |
| u02 | なんばんめ | A(1)ア(イ)、B(1)ア(ウ) | 選択（並んだ絵をタップ） |
| u03 | いくつといくつ | A(1)ア(エ) | 入力（10の合成分解）／分ける |
| u04 | たしざん（あわせて・ふえると） | A(2)ア(ア)(ウ) | 入力／並べ替え（式を作る） |
| u05 | ひきざん（のこりは・ちがいは） | A(2)ア(ア)(ウ) | 入力／分ける |
| u06 | 0のけいさん | A(2)ア(ア) | 選択・入力 |
| u07 | ながさくらべ | C(1)ア(ア)(イ) | 選択（2択）／入力（クリップ何こぶん） |
| u08 | かずしらべ | D(1)ア(ア) | 選択（絵グラフを読む） |

予備（教科書会社によって1学期に入る）：10よりおおきいかず、なんじなんじはん → `docs/study-game/questions/` にJSONを足すだけで追加できる。

**1学期は くり上がり（8+5）を出さない。** 和は10以内、ひき算は10以内。

### 難易度（全単元で共通の定義）

段は「与える足場の量」で決める。

| 段 | 足場 |
| --- | --- |
| level 1〜2（やさしい） | 絵・図あり、選択肢3つ、数は5まで |
| level 3（ふつう） | 絵はあるが並びがばらばら、選択から入力に変わる、10まで |
| level 4〜5（すこし難しい） | 絵なしのことばだけ、ちがいはいくつ（求差）、2文 |

### 問題文の決まり

- ひらがな・カタカナのみ（**漢字は1字も出さない**）。1行15字以内、2文まで
- 助数詞は「こ・ほん・ひき・まい・だい」
- 数字は半角。読み上げが無くても、数と図だけで解けるようにする
- 単位は使わない（長さは「クリップ ○こぶん」）
- 教科書・市販教材を写さない。すべてオリジナル

## 5. 覚えるための仕組み

**管理の単位は「1問」ではなく「スキル」**（例：`u04-awasete-10` ＝ 和が10までのあわせていくつ）。
1学期で約30スキル。

- **間違えた問題**：3問後にもう1回（同じ型・別の数字）。正解したら12問後に確認の1回。
  2回続けて正解でその日は終了。2回目も間違えたら、絵つきの易しい形で3問後にもう1回（1日最大3回）
- **間隔をあけた復習**：stage 0→1日後、1→2日後、2→4日後、3→7日後、4→14日後、5→30日後。
  正解で+1、間違いで−1（下限は1日後）。日付だけで管理し、**時刻は使わない**
- 開けなかった日の分は繰り越す。1回の復習枠は**上限8問**（期限切れが古い順）
- **難易度の自動調整**：直近5問の正答率80%以上かつ連続3問正解で +1（1回で最大2段階、2回続けて条件を満たしたときだけ）。
  連続2問不正解で即 −1。下限1。**下げたことは画面に出さない**
- **制限時間は入れない**（読む速さを測ってしまう）。36秒を超えたら、カウントダウンなしで「ヒント みる？」を静かに出す
- その回の正答率が60%を下回ったら、残りはできるレベルに固定して**「できた」で終わらせる**

### 「きょう できるように なったこと」

点数・正答率・順位は出さない。動詞で書く。

```
・5と いくつで 10 が じぶんで できた
・あわせて いくつ が まえより はやく できた
・いちばん むずかしかった もんだい： 7 + 3 = 10
```

評価の言葉は3つだけ：**はじめてできた／まえよりはやくできた／ばっちりおぼえた**

## 6. モンスター・町・アバター

### つなげ方

- **目的＝町づくり**（1年かけて育つ唯一の長期目標）
- **手段＝モンスター**（学習そのものの入れ物）
- **橋渡し＝アバター**（15分の中の即時の手応え）

### モンスター（もやもや）

「まちがいのもと」という設定。**倒す＝その型の問題を続けて正しく解くこと。**

- **負けは作らない。** 子ども側にHPも制限時間もない
- 間違えたら「もうすこし！」＋正しい答えを3秒見せ、モンスターが**へんしん**して同じ型を出し直す
- 3回間違えた型は、ヒントを出したうえで「また こんどね」で退場（記録に残り、後日もう一度出る）
- 倒したモンスターは**なかまになって町で暮らす**（子ども役がいちばん望んだ要素）

### 材料と建物

材料は4種（**き・いし・ガラス・ねんど**）。**乱数は使わない。**

- 正解1問＝材料1個（どの材料が出るかは**問題の種類で決まっている**。ステージ入口に予告を出す）
- 1回（15分）でもらえる材料は**最大12個**
- 取り組んだ問題（間違えた問題も）には「ねんど」が少量つく（遅い子の町も育つように）
- 建物のコストは固定で、**1年間変えない**（家＝き20、とう＝いし30）。1棟はおよそ2日分

1学期の建物は8棟（単元1つに1棟）：**かずのいえ／ならびのもん／わけっこハウス／たしざんこうじょう／ひきざんそうこ／ゼロのいずみ／はかりのとう／しらべやぐら**

建てると3つ起きる：① その建物から復習問題が出る ② なかまが1人増えて動く・あいさつする ③ みにつけるものが1つ増える
建物の色は子どもが選べる（子ども役の「自分が選んだものが動くのがうれしい」に対応）。

### アバター

伸びるのは4つのちからだけ：**かぞえる／くらべる／かたち／よみとく**
（1学期は「かぞえる」「くらべる」が主に伸びる）

- **レベル＝その力で「できた」になったスキルの数。** 経験値バーのような間接的な数は使わない
- 画面には「かぞえるちから ★★★☆☆」の星5段階で出す（内部のレベルは隠す）
- 装備は**1学期の範囲では見た目だけ**（学習の抜け道にしない）。ヒントは装備ではなく、
  困っている子全員に静かに出す

### ずかん・称号

- ずかん：なかま（モンスター）／たてもの／みにつけるもの
- 称号は「できるようになったこと」の名前（くりあがりのたつじん、かたちみつけびと…）
- **期間限定は作らない**（取りこぼしはいつでも後から回収できる）

## 7. 画面（8つ）

| 画面 | 役目 |
| --- | --- |
| はじめ | 出席番号（1〜40）とキャラ絵をえらぶ／つづきから |
| まち | **唯一のハブ**。建物・今日のしごと・入口が全部ここ |
| ちず | 今日の3ステージ。順番は子どもが選べる |
| たたかう | 1問＝1画面。ここだけで答える |
| けっか | もらった材料／きょうのまとめ |
| アバター | ちからの星、みにつけるものの着替え |
| ずかん | なかま・たてもの・みにつけるもの |
| きろく | カレンダーに「できた」のしるし（連続日数は出さない） |
| せってい | おと・よみあげ・もじの大きさ・先生モードの入口 |

**戻る導線は常に1つ、常に同じ場所**（左上「← まちへ」64×64px）。階層は2段まで。
たたかう → けっか → まち は一本道（戻れない）。

### 低学年向けの数値（守る）

- タップ領域は最小 **64×64px**、主要ボタン **80×80px**、ボタンの間隔 **16px以上**
- 文字は問題の数字 88px / ボタン 26px / 本文 22px / **最小 20px**（iOSのズーム回避で16px未満は禁止）
- 1画面のボタンは最大4つ（まちだけ5つ）
- `line-height: 1.8`、`letter-spacing: 0.04em`、1行はひらがな14字以内
- コントラストは文字4.5:1以上、主ボタン7:1以上
- 正誤は色だけでなく**○／×の形**も併記

### 色（クリーム地＋木と土の「てづくりのまち」）

| 役目 | 色 |
| --- | --- |
| 背景 | `#FDF6E8` |
| カード | `#FFFFFF` |
| 文字 | `#2B2A28`（純黒は使わない） |
| そら | `#4FA3E3` |
| くさ | `#5BBF6A` |
| つち | `#C98A4B` |
| こはく | `#F2B23C` |
| たたかう | `#FF7A45` |
| せいかい | `#1F8F3C` |
| まちがい | `#D94B3F` |

角丸22px（ボタン28px）、輪郭3px、影は `0 5px 0` の板影（押すと4px沈む）。
**ダークモードは入れない**（`color-scheme: light` 固定）。

### 動き

- **使うのは `transform` と `opacity` だけ。** width/height/top/left/box-shadow/filter のアニメは禁止
- 押下 `scale(.94)` 80ms／正解バッジ 180ms／アイテム 400ms／画面遷移 220ms
- 建物が育つのは**初回1.2秒、2回目以降0.4秒**。どこをタップしてもスキップできる
- `prefers-reduced-motion` で全部止める
- 明滅は使わない（赤の明滅は全面禁止。WCAG 2.3.1）

### 音（Web Audio APIで作る。音源ファイルは置かない）

7種：タップ／せいかい（連続正解で音階が上がる）／もうすこし（小さめ・下げない）／
アイテム／レベルアップ／へんしん／とじる。マスター音量 0.25。
最初のタップで `AudioContext` を作って `resume()`（iOSの決まり）。**音は必ず見た目の反応の付属物**にする。

### 読み上げ

`speechSynthesis`（`lang: 'ja-JP'`）を使う。声が無い端末ではボタンを隠す。
**読み上げが無くても解ける問題文**にする（数と図で成立させる）。

## 8. 先生の使い方

| 困りごと | 答え |
| --- | --- |
| 1年生はコードを打てない | **かいほうコードは先生の端末だけで入れる。子どもは触らない** |
| ふつうはどう進むのか | ステージは**子どもの進度で自動開放**される。先生は何もしなくてよい |
| 転入・欠席の子を追いつかせたい | 先生モードで4桁コード（例 `0402` ＝ 単元04・段02）。**累積開放**なので1回で追いつく |
| 全員の進み具合が見たい | サーバーがないので一覧は作れない。子どもの画面に「きょう ◯もん せいかい」を大きく出し、机間巡視で見る |
| 授業で時間を変えたい | 先生モードで 5/10/15/20/45分のタイマーに差し替え（終わると自動で元に戻る） |
| 端末を共有している | 保存枠は最大6つ。出席番号＋キャラ絵で選ぶ。他の枠の記録は見えない |

先生モードの入り方：**タイトルを3秒長押し → 4桁（初回に先生が決める）**

## 9. 技術の方針

### ファイル構成（`public/study-game/`）

1ファイル30KB以下、全部で300KB以下を目安（プレビューの500KB制限に余裕を持たせる）。

```
index.html              画面の骨組み
css/base.css            色・文字・ボタン
css/screens.css         画面ごとの見た目
js/main.js              起動と画面の切りかえ
js/store.js             保存・読み込み・セーブコード
js/session.js           15分の管理・1日の区切り
js/srs.js               復習と難易度の自動調整
js/quiz.js              出題と採点
js/figure.js            問題の絵（SVGを組み立てる）
js/town.js              町の描画（SVG。建物30個を超えたらCanvasへ）
js/avatar.js            アバターの絵と強化
js/audio.js             Web Audioで音を作る
js/speech.js            読み上げ
js/teacher.js           先生モード・かいほうコード
data/manifest.json      単元の一覧
data/units/*.json       単元ごとの問題
sw.js / app.webmanifest / icon.svg
```

- JSは `<script type="module">`（標準のしくみ）。**ビルド工程は使わない**
- 問題データの原本は `docs/study-game/questions/`。`public/study-game/data/units/` へコピーして使う
- **URLは `/study-game/index.html`**（Next.jsの `public/` は `/study-game/` では404になるため、
  `next.config.ts` は触らずファイル名まで書く）

### 問題データの形

```json
{
  "schemaVersion": 1,
  "unitId": "u01",
  "grade": 1, "subject": "math", "term": 1,
  "title": "10までのかず",
  "skills": [{ "id": "u01-count-5", "name": "5までの かぞえかた", "power": "count" }],
  "items": [
    { "id": "u01-001", "skill": "u01-count-5", "level": 1, "type": "choice",
      "prompt": "りんごは なんこ？",
      "figure": { "kind": "dots", "count": 4, "icon": "apple" },
      "choices": ["3", "4", "5"], "answer": 1,
      "hint": "ひとつずつ ゆびで かぞえよう", "reward": "ki" }
  ]
}
```

- 知らない `type` はその1問だけ飛ばす（残りは遊べる）
- 項目は増やすだけ。意味を変えるときは `schemaVersion` を上げる
- `figure` は絵の描き方を名前で指示するだけ（画像ファイルを持たない）
- **単元を足す手順**：JSONを置く → `manifest.json` に1行足す（コードは触らない）

### 保存（localStorage）

キーは `sg:` で始め、分けて持つ（1つの巨大JSONにしない）。

| キー | 中身 |
| --- | --- |
| `sg:meta` | schemaVersion、更新日時、保存枠の一覧 |
| `sg:p<枠番号>:profile` | 出席番号・キャラ絵・称号 |
| `sg:p<枠番号>:progress` | 開放・クリア・町・アバター・持ち物 |
| `sg:p<枠番号>:srs` | スキルごとの level / stage / nextDue（上限2000件） |
| `sg:p<枠番号>:days` | 1日1行の記録（直近60日） |
| `sg:settings` | 音・読み上げ・文字の大きさ |
| `sg:teacher` | 先生モードの4桁（ハッシュ）・授業タイマー |

- 読み込みは必ず `try/catch` ＋ 型チェック。おかしければ `sg:broken:<日時>` に退避して初期値で起動
- **キー名は変えない。** 形を変えるときは新しいキーを作り、旧キーから読んで変換する（旧キーは消さない）
- 書き込みは1秒まとめ。書けないときは1回だけ知らせる
- **1問ごとの全ログは保存しない**（その日だけメモリに置き、終了時に集約して捨てる）

### セーブコード（端末が変わったとき用）

- 進度だけを載せる（ニックネーム・間違い履歴は入れない）
- ビット列 → Crockford Base32（`I L O U` を使わない32文字）で **20〜26文字**、4文字ごとにハイフン
- 末尾1文字はチェック文字（打ちまちがえを見つける）
- **使うのは先生か保護者**（小1には打てない）。共有・見せ合いの機能は作らない

### かいほうコード

サーバーがないので改ざんは完全には防げない。狙いは「子どもがうっかり先に進めない」程度。
正規化（全角→半角・カタカナ→ひらがな）→ SHA-256 → 先頭10桁を照合表と比べる。
`https` か `localhost` でないと `crypto.subtle` が動かないので、動作確認は簡易サーバーで行う。

### オフライン（PWA）

`sw.js` を `public/study-game/` に置くと効く範囲が `/study-game/` 以下に限られる（サイト本体に影響しない）。
本体は「まずキャッシュ」、問題JSONは「まずネット、だめならキャッシュ」。
キャッシュ名に版を入れ、古い版は消す。

### iPad Safari の注意

`pointerdown` で反応（`click` と混ぜない）／`touch-action: manipulation`／
`-webkit-tap-highlight-color: transparent`／`user-select: none`／`overscroll-behavior: none`／
高さは `100dvh` ＋ `env(safe-area-inset-*)`／`backdrop-filter` は使わない／
回転は固定できないので縦横どちらでも成立させる／低電力モードでは30fpsに落ちるので**経過ミリ秒で動かす**。

## 12. 実装してみて分かったこと（第1版をつくった記録 2026-11-21）

### ハマったところ（同じ失敗をくり返さないために）

1. **`hidden` を付けても消えない。** CSSで `.overlay { display: flex }` と書くと、
   HTMLの `hidden` より強くなり、透明な黒い幕が画面全体をふさいでボタンが押せなくなった。
   → `base.css` の先頭に `[hidden] { display: none !important; }` を置いて解決。
2. **同じJSファイルを2回読んでしまう。** `index.html` で `js/app.js?v=1` と書き、
   ほかのファイルからは `../app.js` で読んでいたため、ブラウザが**別のファイル**として
   2回実行していた。時間を数えるタイマーが2つ動き、**15分が7分半で終わる**状態だった。
   → `index.html` からは `?v=` を付けずに読む（CSSは1か所からしか読まないので付けてよい）。
3. **並べ替え問題で札が出ない。** 作った要素を画面に入れ忘れていた。
   → 動作確認は「見た目を見る」だけでなく、**全部の問題形式を1回ずつ実際に解く**。

### じどう読み上げは、はじめ「オフ」にした

教室で30台が一斉に読み上げると先生の指示が通らない（先生役の指摘）。
読み上げ**ボタン**はいつでも押せる。先生がせっていで「もんだいを じどうで よむ」を
オンにできる。

### かいほうコードは、わざと かくしていない

4桁の数字はハッシュにしても総当たりで破られる。**子どもがたどりつけない場所に置く**
（タイトル3秒長押し＋暗証番号）ほうが実際の守りになるので、コードは平文のまま、
先生の画面の中だけで使う。

### 実測した数字（2026-11-21・Windowsのブラウザで）

| 測ったもの | 結果 |
| --- | --- |
| 初回の読み込み | 25ファイル・160KB・DOMContentLoaded 63ms（ローカル） |
| 画面の切りかえ中のなめらかさ | 60fps（いちばん遅いコマ 17ms） |
| 押してから画面が変わるまで | 10ms |
| 連続タップ（同じ答えを5回） | 1回ぶんだけ数えた（二重に数えない） |
| ボタンの大きさ | いちばん小さいもので 幅79px・高さ64px（目標44px以上） |
| よこスクロール | 375px幅・768px幅ともに なし |
| セーブコード | 書き出し→こわす→もどす で完全に一致。1文字変えるとエラーになる |

**確かめられていないこと**：iPadの実機、オフライン（PWA）の動作。
検証用ブラウザがService Workerを使えないため、プレビューURLを実機で開いて確かめてほしい。
