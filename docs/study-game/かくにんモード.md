# かくにんモード（おとな用）

ふだんの決まりを外して、**全部の機能をその場で確かめる**ためのモードです。
教室で配る「先生のつかいかた」には**書いていません**。大人が確かめるときだけ使います。

## つけかた（4ステップ）

1. ゲームのはじめの画面で、**タイトル「かずのまち」を3秒ながおし**する
2. せんせいモードが開く（あんしょうばんごうを決めていれば、それを入れる）
3. いちばん下までスクロールして、**「かくにんモード（おとな用）」**のカードを出す
4. **「オフ」のボタンをおして「オン」にする**

入っている間は、画面のいちばん上に黒い帯で
**「かくにんモード（おとな用）」**と出ます。切りわすれを防ぐためです。
消すには、同じボタンをもう一度おして「オフ」にもどします。

## 入っている間、外れるもの

| ふだんの決まり | かくにんモード |
| --- | --- |
| 1日15分で「きょうはおしまい」になる | 時間で止まらない |
| ざいりょうは1日12個まで | 上限なし（何個でも） |
| 単元は前から順にしか開かない | 16単元ぜんぶ開く（算数8・国語8） |
| 同じ日に1つの力は1段までしか上がらない | 何度でも上がる（すぐ「ばっちり」まで行ける） |
| 新しい枠を作るとき「きょうはたくさんあそびました」で止まる | 止まらない |

## カードの中の道具（5つ）

| ボタン | すること |
| --- | --- |
| きょうの分を リセット | つかった時間と、きょうのざいりょうを0にもどす |
| ざいりょう +100 | 4種類すべて100ずつ足す（建物を建てて見るため） |
| ふくしゅうを いま出す | ぜんぶの問題の「つぎに出す日」をきょうにする |
| ぜんぶ ばっちりに | 全スキルを「ばっちりおぼえた」にする（レベル・武器・称号をまとめて見る用） |
| この子を まっさらに | いま開いている子の記録だけを消す（他の子は消えません） |

## 気をつけること

- かくにんモードで遊んだぶんも、**ふだんの記録と同じ場所にのこります**。
  子どもに渡す前に「この子を まっさらに」で消してください。
- 子ども向けの決まり（15分・12個・順番）は**何も変えていません**。
  このモードを切れば、すぐふだんどおりにもどります。
- 入口はせんせいモードの中だけなので、子どもが自分でたどりつくことはありません。
