- 番号の取り違えが必ず起きる（確認の一手がほしい）

### 学習の専門家（コードを読んでの指摘）→ **4件は本物のバグ**

1. **同じ日に3回正解すると、その日のうちに「ばっちりおぼえた」になる**
   （間隔をあける仕組みが、ただの集中練習に化けていた）
2. **出題がスキルを一巡しておらず、単元の最後のスキルが永久に出ない**
   （そのため単元が100%にならず、「きょうの しごと」が何週間も変わらない）
3. 「12問後に確認」が実装されていない
4. 正答率60%を下回ったときの救済が実装されていない
5. まちがえると出し直しで問題が増え、まるの数が増える（まちがえた子ほどゴールが遠い）
6. セーブコードで戻した記録は「つぎに出す日」が空で、復習に一度も出てこない

### 安全・健康担当（コードを読んでの指摘）→ **抜け道が3つ**

1. **じゅぎょうタイマーを押すと、その日に使った時間が0に戻る**（＝無限に遊べる）
2. **暗証番号が未設定のとき、子どもが せってい画面から自分で登録できる**
   （以後、先生が入れなくなり、子どもはタイマーを押し放題）
3. 端末の時計を前に戻すと1日をやり直せる／新しい枠を作ればごほうびもやり直せる
4. れんしゅうモード（時間切れ後）でも、なかまが増え次の単元が開いていた
5. 起動しただけで最後の子の記録が開く（次の子に前の子の町と記録が見える）
6. `prefers-reduced-motion` が画面遷移にしか効いていない

### UI・アート担当（コードを読んでの指摘）

1. オレンジのボタンに白文字＝コントラスト2.6:1（読めない）
2. わく線と影が1.6:1（「押せる物」に見えない）
3. **画面の入りアニメーションが実際には1つも動いていない**（display切替と同じコマでopacityを変えていた）
4. まちがえたときの2.2秒が飛ばせない
5. 問題カードがスクロールするので、答えのボタンが隠れうる／「やめる」が48pxで小さい
6. 「これで はじめる」が画面外にあり、押せない理由も出ない
7. 絵の大きさが固定で、縦が余っても大きくならない
8. すすみぐあいが色だけ／正誤が色だけ／材料の札が折り返して町をつぶす
