## ゲームプランナーの設計

### A：HPと「負け」の切り分け

- **HPはもや（モンスター）だけが持つ。子ども側のHPは作らない。**
- 正解で「もやのこさ」が減る。**間違えても増えない（減らないだけ）**
- 15分で削りきれなくても負けではなく「うすくなった」。**残りを次回に持ちこす**
- 子ども側は **MP（きあい）** だけ。正解でたまり、必殺技で減る。0でも負けではない

### B：強くなるほど勉強量が減る問題

- こうげき力は「1問で削る量」ではなく **「どの段のもやへ行けるか」** に効かせる
- もやのHPは段と学年に比例。**1体に必要な問題数は学年ごとに固定**（小1：6〜8問、小2：8〜10問…）
- 歯止め3つ：①1体あたり最低6問 ②**とどめの1問はかならず自分で解く**（まとめ削り禁止）
  ③こうげき力の上限は「いま開いている段」
- 「かいしんのいちげき」は**ヒントなしの自力正解のときだけ×2**（運ではなく条件）
- 固い敵が作業に見えない見せ方：6〜8問で**3回すがたが変わる**（もやもや→顔が出る→素顔）。
  HPは数ではなく**4枚の板**で、1問ごとに1枚割れる。残り1枚で背景色が変わる

### C：運を使わずにワクワクさせる

- ずかんに全部を**影で並べ**、取り方を1行で書く（「10は いくつと いくつ を ばっちり おぼえる」）
- ワクワクの正体を「何が出るか」から **「あと2つで来る」「3つのうちどれを先に取るか」** に置きかえる
- 今日の3ステージにそれぞれ別の確定報酬をぶら下げ、順番は子どもが選ぶ

### D：技が学習の抜け道にならないようにする

技がやるのは3つだけ。

1. **見せ方**：ことばだけの問題に●の絵を呼ぶ（答えは出ない）
2. **まち**：倒したあと材料+1、花+1、色が増える
3. **もや**：選択肢を並べる・静かにさせる・字を大きくする（使いやすさの機能を技の顔で出す）

抜け道封じ：**技で解いた問題は「ひとりでできた」にならず「どうぐでできた」になり、おぼえ段を上げない。**
ずるをしても先に進まないので、禁止しなくてよい。

## 安全・健康担当の意見（反対寄り）

- **いちばん危ないのは「成長の数字が見えること」**。経験値と攻撃力が見えた瞬間、
  子どもは問題を解く理由を「数字を上げる」にすり替える
- やめたほうがよいもの3つ：①経験値の数値表示とレベルアップ演出 ②HP・MP・攻撃力の数値
  ③武器・技の図鑑やコンプリート率表示
- 2教科になるときは **15分は2教科の合計**。「今日は算数の日／国語の日」と自動で交互にし、
  同じ日に両方を求めない。レベルは教科で分けず全体で1本

→ **まとめ役の判断**：数字は出す（運営者の方針）。ただし
「**やさしい問題の速解きが最も得になる数値にしない**」を絶対条件とし、
見せる数字はレベルと今日の結果までに絞る。経験値の細かい増減と攻撃力の数値は裏に置く。

## 子ども役の意見

- いちばんうれしいのは**武器**。「この単元をおぼえたらこの武器」と先に分かるのがいい
- **HPとMPは「いらないかも」**。まちがえてもやられないのに、HPがあっても意味がない
- レベルアップは、数字より**アバターの見た目が変わる**のがいちばんうれしい
- 技は「でっかい技でいっぺんに倒す」「まちに畑を一瞬で作る」がやりたい
- 国語より**算数から**。「ことばのまち」という名前は好き
- まだ足りない：もやもやの種類／町がいっぱいになったあとの楽しみ／アバターを見せたい／日替わりの変化

## 教育内容担当（国語）の設計

**裏取りずみ**：<https://erid.nier.go.jp/files/COFS/h29e/chap2-1.htm>
（国立教育政策研究所 学習指導要領データベース／平成29年告示 第2章第1節 国語）。
別表「学年別漢字配当表」も同ページにあり、**第1学年は80字**と明記されている。

### 「1学期はひらがな、漢字は2学期以降」でよいか → **正しい**

1. 〔知識及び技能〕(1)は、**ウ（仮名の読み書き）がエ（漢字）より前**に置かれている
2. 1年の漢字は「読み、**漸次**書き」＝年間を通して少しずつ、と書かれていて時期を定めていない
3. 第1学年は80字しかなく、年間に薄く配分する前提

（単元の並びと、カタカナ・漢字の導入時期の「教科書各社の実際の配列」は**推測**。
指導要領は単元・配列・時期を定めていない）

### 1学期の単元（8つ）

1. ひらがなを読む・見分ける（形の似た字）
2. ひらがなの並び（あ行〜わ行、行と段）
3. 長音・拗音・促音・撥音の表記
4. 助詞「は・へ・を」
5. 句読点・かぎ（「 」）
6. ことばのまとまり（語彙・仲間分け）
7. 主語と述語（だれが・どうする）
8. 事柄の順序（短い文を順に並べる）

**カタカナは単元8のあとに独立したオプション単元**として置き、先生が順番を入れ替えられるようにする
（1学期末に入れる教科書と2学期に回す教科書があるため）。

### この仕組みでは扱えないこと（ゲームでやらないと線を引く）

- **B書くこと（年間100単位時間）**。要領が「実際に文章を書く活動をなるべく多く」と明記しており、
  文字入力をさせない設計では**原理的に扱えない**
- **書写**（姿勢・筆記具・筆順・点画）。画面のなぞり書きは代わりにならない
- **A話すこと**（声の大きさ・速さ、話をつなぐ）
- **長い文章の読解**（場面の様子、登場人物の気持ち、感想の共有）。1行15字・2行では成立しない
- **言語文化**（昔話・言葉遊びの既存作品、読書）。既存作品は載せられない

**保護者向けの文言案**：「ことばのまちは、ひらがな・カタカナ・ことば・文のきまりを**たしかめる**
ゲームです。書く・話す・お話を読むことは、教室と本でやります。」

**「書く」の代わり**：①**ならべる**（字カード・文カードの並べ替え）を中心に据える
②**マス埋め**（空きマスに字カードを入れる）③**音読ボタン**（声に出す→自己申告。正誤判定しない）

### 実装で変えないといけないところ

| 変えるもの | 内容 |
| --- | --- |
| `answer` の形 | 単値だけでなく**配列も許す**（「ならべる」が国語では主役になるため） |
| 新しい図の種類（3つだけ） | **文字カード**（大きな文字のボタン）／**マス枠つき文字列**（`きっ_て`）／**スピーカー** |
| 単元ごとの `allowedChars` | **その時点でまだ習っていないひらがなを問題文に使わない**ための許可文字リスト |

**そのまま使えるもの**：問題データの形、3〜4択、丸つけ、保存、町、ごほうび、既存のSVGの絵

### いちばんの設計課題：未習のひらがな

1学期の前半はまだ読めない字があるのに、問題文はひらがなで書かれる。
**単元ごとに許可文字リストを持たせ、問題文と選択肢がその文字だけで書けているかを
機械でチェックする**仕組みを入れないと、必ず破綻する（算数には無い概念）。

### 「漢字れんしゅう」ツールとの住み分け

- 既存ツール＝**網羅型**（学年を選んで1026字を一覧・印刷。「2年生の漢字を全部おさらい」する場面）
- ゲーム＝**文の中で読めるかだけ**。1単元に5〜10字、2学期以降に少しずつ混ぜる
- ゲームのクリア画面から「もっと練習する → 漢字れんしゅう」へリンクし、網羅はツールに任せる
- ゲームで「漢字を全部練習」をやろうとすると、文字入力なしの制約で**劣化版の練習帳**になり、
  既存ツールと食い合う

## システムデザイナーの数値設計

### いちばん大事な1行

```
もやもやのHP = こうげきりょく × (1体の問題数 + 3)
```

**こうげきりょくが両辺に入っているので、武器をいくら強くしてもHPが同じ倍率で上がり、
1体を倒すのにかかる問題数は変わらない。** 「強くなるほど勉強量が減る」を式で封じている。

- 1問正解 → HPが こうげきりょく のぶん減る（バーは常に 1/8 ずつ減って見える）
- まちがえても減らない（解き直して正解で減る）
- **とどめ**：最後の問題に正解したら、残りHPがいくつでも0になる
  → 技を使っても使わなくても、**かならず決められた問題数で倒れる**

| 学年 | 1体の問題数 | HPの式 |
| --- | --- | --- |
| 小1・小2 | 8問 | ATK×11 |
| 小3・小4 | 10問 | ATK×13 |
| 小5・小6 | 12問 | ATK×15 |

`ATK = 10 + 2×(レベル−1) + 武器 + きたえ`

### 経験値（やさしい問題の速解きが得にならない設計）

| できごと | 点 |
| --- | --- |
| **はじめて「できた」** | **+30** |
| **日をまたいでおぼえていた**（復習で正解） | **+12** |
| ばっちりおぼえた | +40 |
| 単元をひとつ終えた | +100 |
| 正解 level4〜5 | 6 |
| 正解 level3 | 4 |
| 正解 level1〜2 | 2（**1回で合計24点まで。以降は1点**） |
| 同じスキルの2回目以降 | 1 |
| もやもや1体たおした | +10 |
| 1日の合計上限 | 360（超えたぶんは翌日にくりこし） |
| 練習モード（15分のあと） | **0** |

**「同じ15分なら、新しい単元に進んだほうが必ず得」の検算**

| | やさしい問題を周回 | 新しい単元に進む |
| --- | --- | --- |
| 合計 | **158点** | **241点** |

差は**+83点／回**。しかも速く解いても1点も増えない（1回は3体×8問＝24問で打ち止め）。

### レベル

```
つぎのレベルまで = 50 × いまのレベル
Lv N までの合計   = 25 × N × (N−1)   上限 Lv99
```

1学期の終わりで、正答率75%→Lv20／85%→Lv22／95%→Lv23。
**正答率に20%の差があってもレベル差は3**。小6の終わりでちょうどLv99に届く。

### MP（きあい）と技

- 上限100。**1問こたえるごとに+13**（正解でもまちがいでも同じ＝まちがえた子も技を撃てる）
- 1回のはじめに0。**時間では回復しない。日をまたいで持ちこさない**
- 技6つ（こえだし／きあいだま／かぞえのひかり／ひきざんぎり／まちのちから／ことばのうた）
- **ヒント系・選択肢を消す系は1つも入れない**（学習の抜け道を作らない）

### 武器（運なし・ぜんぶ予告つき）

単元を1つクリアで1本、確定。かずのつえ+2／ならびのけん+4／わけっこハンマー+6／
たしざんブレード+8／ひきざんのやり+10／ゼロのほし+12／ものさしぼう+14／しらべのつえ+16。
**最強装備でも8問のまま**（HPが連動するため）。

### 2教科になったとき

| 項目 | 判断 |
| --- | --- |
| 経験値・レベル・武器・こうげきりょく | **共通（1人に1つ）** |
| 1日の上限360 | **1人につき360**（教科ごとにしない＝2教科で720にしない） |
| 復習・星・単元・建物・材料 | **教科べつ** |

理由：15分は1人に1つしかない。経験値を教科で分けると、15分を分け合うだけで両方半分になり、
「両方やると損」になる。共通なら、どちらを選んでも損しない。

### 本人が挙げた「破綻しそうなところ」

1. **ATKが上がってもバーの減り方が変わらず、成長が見えない**（最大の危険）
   → バーは1/8固定のまま、成長は**数字の桁**で見せる（Lv1「10」→Lv22「78」）
2. 中盤（20〜40回目）が経験値の谷になる → 問題数の多い単元を中盤に置く
3. 上限360と単元クリア100がぶつかる日がある → 超過分はくりこし
4. 「ばっちり」が学期末に集中する（1日1段のため最短3日）→ 学期末の式典と重なるので許容
5. 武器の強化が材料を食い切って建物が建たない → 上の「きたえは建物のあと」で防ぐ
6. わざと間違えて技を撃つのが得にならないか → 技は経験値も材料もほぼ増やさないので得にならない
7. 「最後の1問だけがんばればいい」に見えないか → とどめが無視するのは残HPだけ。
   1〜7問目は材料と経験値を生むので手抜きは損
8. 正答率の低い子に不利でないか → まちがえた子は復習が1日後に戻るので復習点を取りやすい。
   **75%と95%で1.27倍しか開かない**

## まとめ役の見立て（この設計をどう扱うか）

**採用したい**：HPの式（問題数が減らない保証）、経験値の順序と上限、武器＝単元クリア、
2教科で経験値を共通にする判断。どれも理由が数で示されている。

**変えたいところ**：

1. **アバターのHPは作らないほうがよい。** この案は「0になっても何も起きない」としているが、
   何も起きないバーを出すと「負けるのかも」と思わせるだけ。
   子ども役も「HPがあっても意味がない」と言っている。
   → **むきず（ノーミス）だけを、きろく画面のしるしで見せる**形にしたい
2. **1回の問題数が、レベルデザイナーの案（20問）と食いちがっている**（この数値は24問が前提）。
   20問にするなら経験値がおよそ17%減るので、どちらかにそろえる必要がある
3. **一度に全部は入れない。** 経験値・レベル・HP・MP・技・武器・きたえを同時に入れると、
   小1には見るものが多すぎる。**3段階に分けて入れる**ことを提案する

### 実装の順番（まとめ役の提案）

| 段階 | 入れるもの | ねらい |
| --- | --- | --- |
| 第1段 | **敵のHP（複数問で倒す）＋武器（単元クリアで確定）＋レベル（見た目が変わる）** | いちばん手ごたえが増え、いちばん壊れにくい |
| 第2段 | 経験値の数値表示・MP・必殺技 | 第1段で15分が崩れないことを確かめてから |
| 第3段 | きたえ・なかまのどうぐ（余り材料の使い道） | 建物8棟が建ち終わる時期に合わせて |
