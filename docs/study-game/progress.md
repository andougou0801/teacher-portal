## 2026-11-22 RPG化の第1段

**入れたもの**

- **敵のHP**：1ステージ＝もやもや1体。正解1問でHPが減り、バーが1こま減る。
  **さいごの1問に正解すると、のこりが いくつでも0になる（とどめ）**
  → 式は `もやもやのHP = こうげきりょく × (問題数 + 3)`。こうげきりょくが両辺に入るので、
  **どれだけ強くなっても1体にかかる問題数は変わらない**（小1は8問）
- **武器8本**：その単元のスキルを**ぜんぶ ばっちり**にすると1本もらえる（運なし）。
  強いほうを自動で装備。じぶん画面で付けかえられる
- **レベル**：`1 + ばっちりおぼえたスキルの数`。じぶん画面にレベルとこうげきりょくを出す
  （たたかう画面には数字を出さない）
- もやもやは こさが減るほど うすく・小さくなる

- 第3段：つえのきたえ・なかまのどうぐ（余り材料の使い道）

## 2026-11-22 国語のなぞり書きと、かくにんモード

### できたこと
- **ひらがな46字の筆順データ**（`js/hiragana-strokes.js`）。端末のフォントと並べて1字ずつ目で確かめ、
  読みちがえる14字（き・ぬ・ふ・め・よ・ら・を など）を直した。
- **なぞり書きの問題**を国語j01に25問追加。新しい力「かくちから」。
  やさしい字（い・こ・し・つ・く）から、むずかしい字（ぬ・ね・を・も・れ）まで5段階。
- **かくにんモード**（`js/debug.js`）。せんせいモードの中からオン・オフ。
  - 時間で止まらない／ざいりょうの1日の上限なし／単元は16こぜんぶ開く／段は同じ日に何度でも上がる
  - 新しい枠を作るときの「きょうはたくさんあそびました」も出ない
  - 入っている間は画面の上に帯「かくにんモード（おとな用）」
  - 確かめる道具5つ：きょうの分をリセット／ざいりょう+100／ふくしゅうをいま出す／ぜんぶばっちりに／この子をまっさらに
- 問題の検査・公開スクリプトを `trace` に対応（筆順データにない字はエラーにする）。

### 実測（ローカルのブラウザで確認）
| 見たこと | 結果 |
| --- | --- |
| かくにんモードをオンにして帯が出るか | 出る（オフにすると消える） |
| 15分（900秒）を超えても止まらないか | つかった時間2000秒・制限900秒でも「おしまい」にならない |
| ざいりょうの1日の上限（12）を超えても増えるか | 30個持っていても もらえる状態 |
| 単元がぜんぶ開くか | 16単元すべて（u01〜u08・j01〜j08） |
| なぞり書きがたたかう画面で動くか | 「く」をなぞって次の問題（「い」）へ進んだ |
| 問題データの検査 | 657問・48スキル・エラーなし |
