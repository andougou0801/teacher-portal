# コラムと学級経営の記事の書き分け

2026-10-30に決めた方針。**テーマで分けようとするとかぶる。役割で分ける。**

## なぜかぶるのか

コラムも学級経営の記事も、題材は同じ「学級のこと」だからです。
テーマを分け合おうとすると（コラムは働き方、記事は学級経営、のように）、
書けるテーマがすぐ尽きて、結局どちらも書けなくなります。

**同じテーマを両方で書いてよい。かぶるのは中身ではなく「書き方」が同じときだけ。**

## 2つの制約（これだけ守れば、同じテーマでもかぶらない）

| | 学級経営の記事（編集部名義） | コラム（GO！名義） |
| --- | --- | --- |
| 役割 | **やり方**を渡す | **どう感じたか・何を選んだか**を渡す |
| 禁止 | **一人称と感情を書かない** | **手順を書かない** |
| 主語 | 先生（一般） | 自分 |
| 結論 | 言い切る（「〜してみてください」） | 言い切らない（「〜だと思いました」） |
| 読後感 | 明日やることが決まる | 自分も考えてみたくなる |
| 書き出し | 「〇〇の場面では」 | 「こんにちは。GO！です。」 |
| 分量 | 5〜7段落・4分で読める | 6〜9段落・3分で読める |
| 本数 | **1テーマ1本**（穴を埋めていく） | **1テーマ何本でもよい**（角度を変えて何度でも） |

## 迷ったときの判定

> **その文章から「手順」を引き算して、まだ読む価値が残るか。**

- 残る → コラム（残るのは、迷いや選択だから）
- 残らない → 記事（価値が手順そのものなら、一人称はいらない）

## 同じテーマを2本に割る「対の型」

かぶりを避けるのではなく、**対にして両方出す**のがいちばん強い形です。

| テーマ | 記事（やり方） | コラム（選択） |
| --- | --- | --- |
| 個人懇談 | 個人懇談、10分で何を話すか | 懇談で、言えなかったことがある話 |
| 11月のゆるみ | 11月、学級がゆるんできたと感じたとき | 11月に怒りすぎた年の話 |
| 運動会 | 運動会で学級に何を残すか | 勝たせたかったのは誰だったのか |
| 校務の効率化 | （ツール紹介記事） | 2学期の折り返しで、やらないことを決めました |

コラムから記事へ、記事からコラムへ読者が流れると、1テーマで2回読まれます。
**かぶりは、つなげれば回遊になります。**（つなぐ仕組みは B-034 として提案中）

## 書くときの順番

1. 先に**記事**を書く（手順を固める）
2. 書き終えて「ここは手順にできなかった」と思った部分が、**コラムの種**になる
3. コラムでは、その部分だけを一人称で書く。手順は書かずに記事へ渡す

逆の順（コラムを先に書く）だと、手順と感想が混ざった中途半端な1本になりやすいです。

## 下書きの置き場

`docs/drafts/` に下書きを置き、`/admin` から運営者が登録します。
コラムの下書きは、**一人称の部分を運営者が書きかえる前提**で作ります
（実話は `../X運用/実話在庫.md` の行からしか引かない）。
