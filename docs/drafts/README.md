# 記事の下書き置き場

ここにあるファイルは、まだサイトに出ていない記事の下書きです。
サイトには出していません（記事はSupabaseの `articles` テーブルが正で、
`/admin` から運営者が登録します）。

## 公開までの手順

1. 本番サイトの `/admin` を開き、「記事・コラム」→「新規作成」
2. この下書きの「入力欄」の内容を、同じ名前の欄に貼る
3. 「本文」の見出しより下を**全部コピー**して本文欄に貼る
   （空行で段落が分かれる仕組みなので、空行はそのまま残す）
4. まず「下書き」で保存して表示を確認し、よければ「公開」に変える

## 下書きを直したいとき

ファイルを直接書きかえても、サイトには影響しません。
「ここをこう変えて」とセッションで伝えてもらえれば、こちらで直します。
