# 管理画面（/admin）のはじめ方

サイトの記事・ツール表示・Q&Aを、コードを触らずに自分で管理するための準備手順です。
作業はすべて [Supabase](https://supabase.com) の管理画面（ブラウザ）で行います。
**1回だけ**やれば、あとはずっと `/admin` から操作できます。

---

## 手順1：SQLを実行する（テーブルと権限を作る）

1. Supabaseにログインし、このサイトのプロジェクトを開く
2. 左メニューの **SQL Editor** を開く
3. `003_admin.sql` の中身をすべてコピーして貼り付け、**Run** を押す
4. 続けて `004_articles_seed.sql` の中身を貼り付け、**Run** を押す
   （今サイトに載っている13本の記事が、管理画面から編集できる状態になります）

エラーが出なければ完了です。

## 手順2：ログイン用のアカウントを作る

1. 左メニューの **Authentication** → **Users** を開く
2. **Add user** → **Create new user** を選ぶ
3. ご自身のメールアドレスと、忘れないパスワードを入力する
4. **Auto Confirm User**（自動で確認済みにする）をオンにして作成する

> パスワードはご自身で決めて入力してください。開発者側では扱いません。

## 手順3：管理画面にログインする

https://teacher-portal-puce.vercel.app/admin

手順2で作ったメールアドレスとパスワードでログインします。

---

## できること

| メニュー | できること |
| --- | --- |
| 記事・コラム | 記事の追加・編集・削除、下書き保存、掲載先（コラム／授業／学級経営／行事）の指定 |
| ツールの表示設定 | ツールをサイトに表示するかどうかの切り替え、並び順の変更 |
| Q&Aの管理 | 質問・回答の非表示／再表示、削除、通報件数の確認 |

- 変更内容がサイトに出るまで、最大1分ほどかかります。
- **ツール本体（HTMLファイル）の追加・修正は、これまで通り開発者へご依頼ください。**
  管理画面でできるのは「表示する／しない」と並び順の変更だけです。

## 安全のための設計

- 編集できるのは、手順2で作ったアカウントでログインした人だけです
  （Supabase側の権限設定＝RLSで制限しているため、URLを知られても他の人は編集できません）。
- 記事はデータベースで管理しますが、**万一データベースに接続できないときは、
  `src/lib/articles.ts` に残っている記事が表示されます**（サイトが真っ白にならないようにするため）。
  そのため、記事を追加・修正しても、このファイルは自動では更新されません。
