# 管理画面（/admin）のはじめ方

サイトの記事・ツール表示・Q&Aを、コードを触らずに自分で管理するための準備です。
**1回だけ**やれば、あとはずっと `/admin` から操作できます。作業は2つだけです。

---

## 手順1：SQLを実行する（コピー＆ペースト1回）

1. 下のリンクを開く（Supabaseにログインした状態で）
   👉 https://supabase.com/dashboard/project/eyakvgrrbbjbnyuzqrcj/sql/new
2. このフォルダの **`admin_setup.sql`** の中身を**すべて**コピーして貼り付ける
3. 右下の **Run** を押す

「Success. No rows returned」と出れば完了です。
これで、記事とツール設定のテーブル、権限設定、そして今サイトにある13本の記事の取り込みまで
一度に終わります。

## 手順2：ログイン用のアカウントを作る

1. 下のリンクを開く
   👉 https://supabase.com/dashboard/project/eyakvgrrbbjbnyuzqrcj/auth/users
2. **Add user** → **Create new user** を選ぶ
3. メールアドレスは **andougou0801@gmail.com**（`admin_setup.sql` に管理者として書いてあるアドレス）、
   パスワードはご自身で決めて入力する
4. **Auto Confirm User**（自動で確認済みにする）を**オン**にして作成する

> パスワードはご自身で決めて入力してください。開発者側では扱いません。
> 別のメールアドレスを使いたい場合は、`admin_setup.sql` の `is_admin()` の中の
> アドレスを書き換えてから手順1を実行してください（実行済みの場合は、その部分だけ
> もう一度実行すればOKです）。

## できること

| メニュー | できること |
| --- | --- |
| 記事・コラム | 記事の追加・編集・削除、下書き保存、掲載先（コラム／授業／学級経営／行事）の指定 |
| ツールの表示設定 | ツールをサイトに表示するかどうかの切り替え、並び順の変更 |
| Q&Aの管理 | 質問・回答の非表示／再表示、削除、通報件数の確認 |

- 変更内容がサイトに出るまで、最大1分ほどかかります。
- **ツール本体（HTMLファイル）の追加・修正は、これまで通り開発者へご依頼ください。**
  管理画面でできるのは「表示する／しない」と並び順の変更だけです。

## 安全のための設計

- 編集できるのは、`admin_setup.sql` の `is_admin()` に書かれたメールアドレスでログインした人だけです。
  Supabase側の権限設定（RLS）で制限しているため、管理画面のURLを知られても他の人は編集できません。
  （誰かが勝手にアカウントを作っても、そのアドレスでなければ何も編集できません）
- 記事はデータベースで管理しますが、**万一データベースに接続できないときは、
  `src/lib/articles.ts` に残っている記事が表示されます**（サイトが真っ白にならないようにするため）。
  そのため、記事を追加・修正しても、このファイルは自動では更新されません。
